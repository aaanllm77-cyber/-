# Select — сайт для GitHub Pages

Файли: `index.html` (магазин), `admin.html` (адмін-панель, посилання у футері), `products.js` (дані товарів), `config.js` (хеш пароля), `images/`.

## Публікація
Завантажте вміст папки в репозиторій → Settings → Pages → Deploy from branch (main, /root).

## Адмін-панель
`/admin.html`, пароль за замовчуванням: **select2026** — змініть його одразу (кнопка «Змінити пароль» → замінити `config.js`).

## Як змінити товари
1. Увійдіть в адмінку, додайте/відредагуйте/видаліть товари.
2. «Завантажити products.js» → замініть файл у репозиторії → commit.
3. Нові фото кладіть у `images/…` і вказуйте шлях у товарі.

Примітка: пароль на статичному сайті лише ховає інтерфейс редагування. Реальний захист — що змінити сайт можна тільки через commit у ваш репозиторій.
