Публікація змін

Зміни зберігаються лише у вашому браузері (чернетка). Щоб вони з'явились на сайті:

  1. Натисніть «Завантажити products.js».
  2. У репозиторії GitHub замініть файл products.js завантаженим (Add file → Upload files, або перетягніть у папку репозиторію).
  3. Зробіть commit — за хвилину GitHub Pages оновить сайт.

Нові фото покладіть у папку images/ репозиторію й вкажіть шлях у товарі, наприклад images/care/krem.webp.
